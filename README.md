# SiA

Ferramentas de consulta e acompanhamento acadêmico.

## SiAPos

O [SiAPos](SiAPos/) reúne indicadores agregados da pós-graduação do IME-USP: titulações, matrículas, disciplinas e o quadro comparativo de 2024–2025. Permite selecionar programas e anos, comparar gráficos e consultar a referência de cada indicador.

O site é estático. A pasta `SiAPos/` contém os cinco arquivos necessários para execução; não exige servidor de aplicação, instalação ou serviços externos. Pode ser servida pelo GitHub Pages ou aberta localmente pelo arquivo `index.html`, mantendo os demais arquivos ao lado dele.

Consulte a [documentação do painel](SiAPos/README.md) para cobertura, critérios e atualização dos dados.

Este repositório público contém apenas a interface, dados agregados e documentação. Fontes autenticadas, planilhas de trabalho, coletas, credenciais e dados nominais ficam fora dele.
